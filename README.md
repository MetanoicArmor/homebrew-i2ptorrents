# homebrew-i2ptorrents

Homebrew tap for [I2P Torrents](https://github.com/MetanoicArmor/i2ptorrents-gui) prebuilt macOS releases.

```bash
brew tap MetanoicArmor/i2ptorrents
brew install --cask i2ptorrents
```

Or:

```bash
brew install --cask metanoicarmor/i2ptorrents/i2ptorrents
```

Cask sources are maintained in the main repo under `packaging/homebrew/Casks/`.
Apple Silicon (arm64) only for CI builds.
